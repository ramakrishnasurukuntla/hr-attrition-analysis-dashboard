## hr-attrition-analysis-dashboard
This project analyzes employee attrition trends and workforce insights using SQL and Ecxel.
The goal of this project is to understand why employees leave the company by analyzing attrition across departments, salary, gender, and job satisfaction.

An interactive Excel dashborad was created to visualize the findings. 

## Tools Used
- SQL
- Excel
- Pivot Tables
- slicers
- Dashboard design

## Key Insights
- Total Employees Analysis
- Attrition Count & Attrition Rate
- Department-wise Attrition Analysis
- Employee Gender Distribution
- Average Salary By Department
- Job Satisfaction Attrition Analysis
